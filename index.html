API Keys

TMDB is required — it does the title matching and tells you stream vs. rent vs. buy. Watchmode is optional and only adds real prices; if it doesn't cooperate from a browser, everything else still works. Keys stay in your browser only.

Get a TMDB key ↗ Get a Watchmode key ↗

New to TMDB? Getting a free key takes about a minute:

  1. Create a free account at themoviedb.org, then verify your email.
  2. Go to your account Settings → API (or use the link above).
  3. Click Create / Request an API Key and choose Developer — describe it as personal/non-commercial use.
  4. On the API settings page you'll see two values. Copy the one labeled "API Key (v3 auth)" — a short string of letters and numbers.
  5. Don't copy the "API Read Access Token" — that's the long one starting with eyJ, and it won't work here.
  6. Paste the short key into the TMDB field above and hit Save — it'll confirm it's working.
